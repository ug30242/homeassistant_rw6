# Redmi Watch 6 Home Assistant v0.1.2

워치 메인화면의 반복 조회 부담을 줄이고 Android에서 즐겨찾기를 바로 설정할 수 있도록 개선했습니다.

- 메인화면은 세션에 저장된 최근 상태를 먼저 표시하고, 필요한 엔티티를 최대 2개씩 병렬 조회합니다. 응답마다 목록 전체를 다시 그리던 작업을 묶어 처리하고, 화면 이동과 ON/OFF 조작이 목록 갱신 완료를 기다리지 않도록 했습니다.
- 재진입·필터 전환 시 갱신 주기 이내의 조회 결과를 재사용합니다 (주기 갱신을 끈 경우 30초). Refresh 버튼은 캐시와 관계없이 재조회합니다.
- 항목마다 Checked 조회 시각을 표시합니다. 조회 실패 시 과거 값을 보존하되 STALE로 표시하고, 오래된 병렬 응답이 제어 결과를 덮어쓰지 않도록 했습니다. 상세화면에서 조회·조작한 결과도 메인화면에 반영합니다.
- Android 엔티티 탭의 선택 목록을 기본으로 펼치고, 각 항목에 ‘즐겨찾기 · 워치 Favorites’ 체크박스를 추가했습니다. 변경 후 워치 탭에서 전체 설정을 동기화해야 워치에 반영됩니다.
- 활성 목록의 30/60/120초 주기 갱신을 유지합니다. 서버 푸시 방식의 실시간 수신은 지원하지 않으며, Android 상주 중계 서비스도 추가하지 않습니다.

## 설치

첨부된 `rw6-ha-android-0.1.2.apk`와 `com.vela.rw6ha.release.0.1.2.rpk`를 모두 업데이트하세요. 기존 릴리즈와 동일한 패키지·공개 인증서를 사용하며, 서명 키가 일치할 때만 게시됩니다. 기존 설정과 동기화 형식은 유지됩니다. 즐겨찾기 변경 후에는 Android 워치 탭에서 전체 설정을 다시 동기화하세요.

## 검증 및 제한

JavaScript 테스트 20개, Android 테스트 26개, APK/RPK 빌드, Android Lint, 컴파일된 워치 4개 화면 smoke 및 Java → 워치 설정 동기화 검증을 통과했습니다. 릴리즈 과정에서는 APK/RPK 서명·인증서·버전 및 SHA256도 검사합니다.

실제 중국판 Redmi Watch 6의 체감 속도·TLS·Mi Fitness 통신·배터리는 추가 확인이 필요하여 사전 릴리즈로 배포합니다. 앱 재시작 시 세션 캐시는 비워지며 첫 진입에는 새 조회가 필요합니다.
