# Redmi Watch 6 Home Assistant v0.1.3

워치 목록을 카드 탐색 전용으로 바꾸고 Android 선택목록 검토 화면을 추가했습니다.

- 워치 메인 목록에서 상태 조회·자동 갱신·ON/OFF 조작을 제거했습니다. 로컬에 저장된 카드만 표시하여 진입·스크롤·필터 변경 시 서버 응답을 기다리지 않습니다.
- 48px 아이콘, 실제 엔티티 종류(Light/Switch/Fan/Cover/Sensor/Scene/Script), 두 줄 이름과 이동 화살표를 표시합니다. 공백을 정리하고 한글 이름은 읽기 쉬운 entity_id 기반 ASCII 이름으로 대체합니다.
- 카드 전체를 터치하면 상세화면에서 해당 항목의 상태를 조회하고 기존 제어를 사용할 수 있습니다. 설정한 30/60/120초 자동 갱신은 상세화면에서만 동작하고 목록으로 돌아가면 중지합니다.
- Android 도메인 분류에 전체 선택 개수를 표시합니다. 검색·페이지 밖의 선택도 포함하고 체크 변경과 삭제를 즉시 반영합니다.
- Android의 별도 선택목록 탭에서 서버 재조회 없이 선택 항목 전체를 검토합니다. 이름·ID·그룹 검색, 도메인·즐겨찾기 필터, 워치 이름 미리보기, 즐겨찾기 변경·편집·전체 순서 이동·삭제를 지원합니다.

## 설치

`rw6-ha-android-0.1.3.apk`와 `com.vela.rw6ha.release.0.1.3.rpk`를 모두 업데이트하세요. 기존 패키지·서명 인증서·설정 형식을 유지합니다. 즐겨찾기·이름·순서 등 Android에서 변경한 설정은 워치 탭에서 전체 설정을 동기화해야 반영됩니다.

## 검증

JavaScript 17개와 Android 30개 테스트, APK/RPK 빌드·Android Lint·Java → 워치 설정 동기화를 검증했습니다. 컴파일된 워치 앱에서 80개 카드 탐색·필터 변경·재진입의 HA 요청/폴링 0건과 카드 터치 후 상세 조회·제어·타이머 정리를 확인했습니다. 릴리즈 과정에서는 기존 인증서 일치, APK/RPK 서명·버전·SHA256도 검증합니다.

중국판 워치와 Android 실기기의 글꼴·렌더링·터치·Mi Fitness 통신·배터리는 추가 확인이 필요하여 사전 릴리즈로 배포합니다.
