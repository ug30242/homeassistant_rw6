# Redmi Watch 6 Home Assistant v0.1.1

Android 엔티티 목록의 대규모 조회 오류와 긴 목록 탐색을 수정했습니다.

- 기존 `/api/states` 전체 응답의 **2 MiB 제한** 때문에 2,000개 이상 엔티티를 조회할 때 발생하던 `서버 응답이 너무 큽니다` 오류를 수정했습니다. JSON을 순차적으로 읽고 이름·ID·도메인만 보관하며 무거운 상태·속성은 건너뜁니다.
- gzip 압축을 지원하고, 목록 응답은 압축 해제 후 128 MiB / 50,000개까지 처리합니다. 대량 조회 읽기 타임아웃은 30초, 전체 읽기 시간 제한은 90초입니다.
- 목록은 조명·스위치·팬·커튼·센서·장면·스크립트의 **도메인별 개수**로 표시하며 처음에는 접혀 있습니다. 한 도메인씩 펼쳐 **50개 단위로 이전/다음 페이지**를 탐색합니다. 이전의 처음 200개 표시 제한을 없앴습니다.
- 검색은 페이지 밖의 전체 지원 엔티티에 적용합니다. 도메인·페이지·탭을 바꿔도 선택 상태를 유지하고, 선택한 엔티티의 편집 목록도 접을 수 있습니다. 워치용 선택 한도는 80개입니다.
- 실제 Home Assistant REST 목록 API에는 도메인별 페이지 요청이 없어 네트워크에서는 전체 응답을 읽습니다. 화면의 도메인 분류·페이지 탐색은 읽어 둔 간단한 목록에 적용합니다.

## 설치

`rw6-ha-android-0.1.1.apk`를 기존 앱 위에 업데이트하세요. 기존 v0.1.0과 동일한 인증서와 패키지를 사용하여 저장된 서버·토큰·선택 설정을 유지합니다. 이 수정은 Android 관리 앱에 적용되며 기존 v0.1.0 워치 RPK와도 설정 동기화 형식이 호환됩니다. 같은 버전으로 맞추려면 첨부된 `com.vela.rw6ha.release.0.1.1.rpk`도 설치할 수 있습니다.

[설치·사용 가이드](https://github.com/ug30242/homeassistant_rw6/blob/v0.1.1/docs/setup.ko.md)

## 검증

- Android 테스트 25개와 JavaScript 테스트 16개 통과. Android APK 빌드 및 Lint 오류 0개.
- 2 MiB를 초과하는 **2,656개 엔티티 응답**으로 스트리밍 조회·지원 도메인 분류를 검증했습니다.
- gzip, 중단·잘못된 JSON, 응답 크기·개수 제한, 도메인 접기/펼치기, 50개 페이지 탐색, 마지막 엔티티 검색, 선택·검색 상태 유지 회귀 테스트를 포함합니다.
- Java → 워치 전송 상호운용, 실제 컴파일된 4개 워치 화면 smoke, APK/RPK 서명·패키지·버전과 SHA256을 확인했습니다.

실제 사용자의 Home Assistant 서버 접속과 Android 실기기 화면 조작은 아직 확인하지 못했습니다. 중국판 워치의 직접 네트워크·Mi Fitness XMS 왕복·Android 강제 종료 후 동작도 계속 실기기 검증이 필요하여 사전 릴리즈로 배포합니다.
